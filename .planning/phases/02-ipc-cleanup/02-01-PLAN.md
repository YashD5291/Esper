<objective>
Replace the os.dup(1) / os.dup2(2,1) stdout redirect hack in server.py with an argparse-based --protocol-fd N argument. When present, JSON events go to that fd via os.fdopen(N, "w", buffering=1). When absent, JSON goes to stdout for CLI debugging.

Purpose: Eliminates the fragile stdout redirect that requires import ordering constraints and would corrupt the protocol stream when log-heavy VAD and Whisper components are added in later phases.
Output: Clean server.py with --protocol-fd support, proven by automated test.
