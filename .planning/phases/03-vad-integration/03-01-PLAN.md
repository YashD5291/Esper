**Module structure:**
```
src/vad.py
- imports: threading, queue, math, collections, logging, numpy, torch, silero_vad
- from . import config
- log = logging.getLogger(__name__)
- class VadThread: __init__, start, stop, wait, _run
```

**VadThread.__init__(self, audio_q: queue.Queue, speech_q: queue.Queue):**
Store audio_q, speech_q, create threading.Event for stop, thread reference.

**VadThread.start(self):**
Create and start daemon thread targeting _run, name="vad".

**VadThread.stop(self):**
Set stop event.

**VadThread.wait(self, timeout: float = 5.0):**
Join the thread with timeout.

**VadThread._run(self):**
Per D-04: `torch.set_num_threads(1)` first line.
Load model: `model = load_silero_vad()`, call `model.reset_states()`.

Compute derived constants (not stored in config — per RESEARCH.md):
- `FRAME_MS = 32` (512 samples / 16kHz)
- `SIL_FRAMES = math.ceil(config.VAD_SILENCE_THRESHOLD_MS / FRAME_MS)` = 16
- `MIN_FRAMES = math.ceil(config.VAD_MIN_SPEECH_DURATION_MS / FRAME_MS)` = 16
- `PRE_FRAMES = math.ceil(300 / FRAME_MS)` = 10 (per D-10: 300ms pre-buffer)
- `POST_FRAMES = math.ceil(200 / FRAME_MS)` = 7 (per D-11: 200ms post-buffer)

Initialize state: `prebuf = collections.deque(maxlen=PRE_FRAMES)`, `speech_buf = []`, `triggered = False`, `silence_frames = 0`.

Main loop (while not self._stop.is_set()):
1. `frame = self._audio_q.get(timeout=0.2)` — catch queue.Empty and continue
2. `if frame is None: break` — sentinel from AudioCapture.stop()
3. **CRITICAL per Pitfall 1:** `prebuf.append(frame)` FIRST (always buffer, even low-energy)
4. Energy gate (per D-09): `rms = float(np.sqrt(np.mean(frame ** 2)))`. If `rms < config.VAD_MIN_ENERGY` and not triggered: `continue` (skip VAD scoring but frame is in prebuf). If triggered: still process (need to count silence).
5. VAD score: `tensor = torch.from_numpy(frame.reshape(1, -1))`, `speech_prob = model(tensor, config.SAMPLE_RATE).item()`
6. **Not triggered + speech_prob >= threshold (per D-06):** Set triggered=True, silence_frames=0, `speech_buf = list(prebuf)`, `prebuf.clear()`
7. **Triggered:** `speech_buf.append(frame)`. If `speech_prob < threshold`: increment silence_frames, else reset to 0.
8. **Silence threshold reached (per D-07):** Collect POST_FRAMES post-buffer frames (audio_q.get with short timeout per frame, append to speech_buf). Check `len(speech_buf) >= MIN_FRAMES` (per D-08). If yes: `utterance = np.concatenate(speech_buf).astype(np.float32)`, `speech_q.put_nowait(utterance)` with try/except queue.Full (log warning, discard). Reset: speech_buf=[], triggered=False, silence_frames=0, `model.reset_states()` (per Pitfall 2).

**Important edge cases:**
- When triggered and frame is low-energy: still count as non-speech (increment silence_frames) but do NOT skip — append to speech_buf and process normally. The energy gate `continue` only applies when NOT triggered.
- `put_nowait` on speech_q (per D-12 and Pitfall 3) — never block the VAD thread.
- Wrap entire _run in try/except to log unexpected errors with exc_info=True (per CLAUDE.md: no silent catches).
