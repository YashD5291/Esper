    New `WhisperTranscriber` class:
    - `__init__(self, *, on_update, on_status)`: callbacks. `on_update: Callable[[TranscriptionUpdate], None]`, `on_status: Callable[[str], None]` for status events. Stores `_sentences: list[str] = []`, `_finalized_text: str = ""`, `_generation_count: int = 0`, `_crash_count: int = 0`, `_stopped: bool = False`, `_proc`, `_audio_q`, `_result_q`.
    - `start(self)`: calls `_spawn_worker()`, waits for ready sentinel up to `config.MODEL_LOAD_TIMEOUT_S`. If `result_q.get(timeout=config.MODEL_LOAD_TIMEOUT_S)` raises `queue.Empty`, kill the subprocess and raise `RuntimeError("Model load timed out after {MODEL_LOAD_TIMEOUT_S}s")` (per ARCH-03 process-level timeout). Emits status events: check if model is cached (`~/.cache/huggingface/hub/models--mlx-community--whisper-large-v3-turbo` exists) — if not, emit `"downloading_model"` via on_status, else emit `"loading_model"` per D-09.
    - `_spawn_worker(self)`: `ctx = multiprocessing.get_context("spawn")`, create `ctx.SimpleQueue()` for audio_q and result_q, `ctx.Process(target=_whisper_worker_entry, args=(audio_q, result_q), daemon=True, name="whisper-worker")`, start it. The `_whisper_worker_entry` is a module-level function that imports and calls `_whisper_worker` from `whisper_worker.py` (avoids pickling issues with spawn context — use `from src.whisper_worker import _whisper_worker` inside the entry function).
    - `transcribe_utterance(self, audio: np.ndarray) -> TranscriptionUpdate | None`: Put audio on audio_q. `result_q.get(timeout=config.WHISPER_SUBPROCESS_TIMEOUT_S)`. On timeout: call `_kill_worker()`, call `self._on_status("error")` per D-06 (emit error event BEFORE _on_failure), then call `_on_failure()`, return None. On result with ok=False: call `self._on_status("error")` per D-06, then call `_on_failure()`, return None. On result with ok=True: check `_is_hallucination(result["result"])` — if yes, log at DEBUG, return None. Else: `_generation_count += 1`, `_crash_count = 0`, build TranscriptionUpdate, call on_update, return it. If `_generation_count >= config.WHISPER_MAX_GENERATIONS_BEFORE_RESTART`: recycle worker.
    - `_is_hallucination(self, result: dict) -> bool`: Extract segments. If no segments or empty text, return True. Compute avg no_speech_prob across segments. If > config.WHISPER_NO_SPEECH_THRESHOLD, return True. Compute avg compression_ratio. If > config.WHISPER_COMPRESSION_RATIO_THRESHOLD, return True. Return False.
    - `_build_update(self, result: dict, audio: np.ndarray) -> TranscriptionUpdate`: text = result["text"].strip(), append to _sentences, join all _sentences into _finalized_text. Compute duration_s = len(audio) / config.SAMPLE_RATE. Compute avg no_speech_prob from segments. Return TranscriptionUpdate(text=text, finalized_text=_finalized_text, sentences=list(_sentences), no_speech_prob=avg_nsp, duration_s=duration_s).
    - `_on_failure(self)`: Increment _crash_count. If >= 3: set _stopped=True, call on_status("crashed"). Else: call _spawn_worker() to restart.
    - `_kill_worker(self)`: If _proc and _proc.is_alive(): _proc.kill(), _proc.join(timeout=5).
    - `stop(self)`: Put None sentinel on audio_q (if worker alive). _kill_worker(). Set _stopped=True.
    - `wait(self, timeout=5.0)`: If _proc: _proc.join(timeout=timeout).
    - Property `stopped -> bool`.

    **IMPORTANT per D-06:** In the timeout path of `transcribe_utterance`, call `self._on_status("error")` BEFORE calling `_on_failure()`. This ensures the Swift UI receives an `"error"` event on Whisper timeout. Similarly, in the ok=False (subprocess error) path, call `self._on_status("error")` before `_on_failure()`.
